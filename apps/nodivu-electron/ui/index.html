Sistema

Microfone virtual · VB-CABLE

  1. Entrada: seu microfone real ou Player MP3.
  2. Saída do Nodivu: CABLE Input.
  3. Microfone do outro app: CABLE Output.

Conecte os blocos por fios. Para voz + MP3, use o Mixer. Não devolva CABLE Output ao próprio cabo.

Instalação e teste

VB-CABLE é um produto VB-Audio, distribuído como donationware; doações são bem-vindas em www.vb-cable.com. Sem o cabo? Use o botão Instalar VB-CABLE acima ou o pacote original de vb-audio.com/Cable, reinicie o Windows e use Atualizar dispositivos. Nenhum padrão do Windows precisa mudar.

Para ouvir o cabo nos fones, use Escuta local e selecione sua saída física. Medidor de envio não comprova recepção; teste também no app de destino.

Se renomeou o cabo no Windows, escolha-o manualmente pelo nome que você definiu.

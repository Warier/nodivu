# Studio Gain — exemplo

Este pacote demonstra um efeito CLAP nativo e controles declarativos do Nodivu. Conecte Fonte → Studio Gain → Saída. Cada instância tem parâmetros independentes.

Na compilação de demonstração com Scale 0.5, Intensidade 1 aplica ganho de 0,5. Use bypass para comparar. O fator de build faz parte deste exemplo de desenvolvimento, não de um controle de volume absoluto. Não precisa de GPU.

## Instalação

Este bloco acompanha o desenvolvimento do Nodivu. Pacotes compilados podem ser importados por pasta ou ZIP no gerenciador de plugins. Alterações entram em vigor ao fechar e abrir o app. Salve o projeto antes.

A versão do pacote é independente da versão do aplicativo. Metadados locais não concedem selo oficial. Consumo ainda sem classificação medida.

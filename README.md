# Canal de atualizações Nodivu Qt

Somente metadados públicos assinados e a oferta de atualização da edição Qt.
Código/ferramentas: [branch qt](https://github.com/Warier/nodivu/tree/qt), [operação do canal](https://github.com/Warier/nodivu/blob/qt/apps/nodivu-desktop/UPDATES.md).

O instalador é um asset por versão na prerelease Qt correspondente. URL, tamanho e hashes são autenticados em targets.json. As chaves privadas não pertencem a este repositório. Timestamp deve ser renovado antes de 14 dias; snapshot 30 dias, targets 90 dias, raiz inicial 365 dias. Renovar com o mesmo instalador também incrementa revisões.

Não alterar a raiz de confiança sem rotação assinada. Não editar JSON assinado manualmente. Este canal não é usado pelo Electron e não altera latest.yml/beta.yml.
